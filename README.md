# Bayshore Medical Personnel website redesign, Draft 1

A clickable prototype of a redesigned medicalpersonnel.ca, shared for internal review at Bayshore HealthCare.

**View it here:** https://edisontsandoval.github.io/BMP-Website-Draft/

This is a draft, not the live site. Text marked in orange still needs facts or approval, the forms and AI features are demos that send nothing, and the hero video is an AI-generated preview that will be replaced with licensed stock footage. Search engines are asked not to index it.
